## 1. Frontend

В осеннем блоке делался именно интерфейс и клиентская часть проекта. Основная задача была сделать сайт конного клуба визуально и функционально рабочим на стороне браузера.

### ЛР 1. Средства гипертекстовой разметки документа

- создание структуры страницы сайта;
- разметка заголовков, блоков, навигации, контента;
- верстка базовых разделов: главная, услуги, цены, лошади, блог.

### ЛР 2. Применение каскадных таблиц стиля

- оформление страницы через CSS;
- работа с цветами, шрифтами, отступами, компоновкой блоков;
- создание визуального стиля сайта: оформление шапки, секций, карточек, футера.

### ЛР 3. Адаптивная вёрстка

- разработка корректного отображения на разных размерах экрана;
- адаптация страницы под мобильные устройства и планшеты;
- улучшение структуры и отзывчивости интерфейса.

### ЛР 4. Добавление пользовательского интерактивного взаимодействия

- добавление JavaScript-логики;
- создание интерактивных элементов и действий пользователя;
- реализация динамического поведения страницы.

### ЛР 5. Разметка веб-форм в runtime и работа с пользовательскими хранилищами

- создание форм для ввода данных;
- работа с localStorage;
- сохранение состояния пользователя и данных в браузере.

### ЛР 6. Обработка HTTP-запросов

- работа с сетевыми запросами и ответами сервера;
- получение и отображение данных из внешних источников;
- обработка ошибок и базовой клиентской логики.

### ЛР 7. Интеграция дополнительных сторонних JS-библиотек и фреймворков

- подключение сторонних библиотек;
- расширение интерфейсного функционала;
- улучшение пользовательского опыта и взаимодействия с сайтом.

## 2. Backend

Во втором семестре проект был направлен в сторону серверной разработки и полноценного веб-приложения. Основная цель заключалась в создании бизнес-логики, хранения данных, API и механизмов безопасности.

### ЛР 1. Деплой на Render и шаблонизация страниц приложения

- развёртывание проекта на хостинге;
- настройка NestJS;
- запуск приложения в интернете;
- подключение шаблонизатора и выделение повторяющихся блоков в partials.

### ЛР 2. Создание доменной модели и её описание

- проектирование сущностей предметной области;
- подключение PostgreSQL и ORM/Prisma;
- создание миграций и ER-диаграммы;
- моделирование данных: пользователи, услуги, лошади, бронирования, отзывы и расписание.

### ЛР 3. Интеграция шаблонов с бизнес-логикой и Server-Sent Events

- создание модулей, контроллеров и сервисов;
- реализация CRUD-логики;
- привязка данных к шаблонам;
- использование SSE для обновлений в реальном времени.

### ЛР 4. Разработка RESTful API и его спецификации

- разработка API-контроллеров;
- валидация входных данных;
- обработка исключений;
- пагинация и Swagger/OpenAPI документация.

### ЛР 5. Разработка схемы GraphQL

- создание GraphQL-модулей и resolvers;
- описание query и mutation;
- работа с вложенными данными;
- использование GraphQL Playground для тестирования запросов.

### ЛР 6. Применение возможностей NestJS для разработки BFF

- измерение времени обработки запросов;
- реализация перехватчиков;
- кэширование ответов;
- работа с S3-хранилищем и загрузкой файлов.

### ЛР 7. Добавление аутентификации и авторизации

- подключение провайдера аутентификации;
- работа с JWT/cookies и сессиями пользователей;
- реализация guard и middleware;
- разграничение доступа по ролям: обычный пользователь и администратор.
